# Homework 2 - Toy ECC, Caesar cipher and attacks

Static page (HTML + CSS + JavaScript, no build step, no dependencies).

## Files
- `index.html` - page structure and text
- `style.css` - styles
- `js/corpus.js` - English and Italian training / test texts
- `js/crypto.js` - secp256k1 arithmetic, SHA-256, toy ECC scheme, attacks, Caesar, language models
- `js/app.js` - user interface, charts and experiments
- `homework2-site.zip` - everything above, used by the "Download all files" button
